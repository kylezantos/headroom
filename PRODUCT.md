# Product

## Register

product

## Users

Headroom is for AI-heavy Mac and iPhone users who need a quick, low-friction read on their AI subscription headroom (Claude, Codex, Grok, Cursor and GitHub Copilot) while working. They are usually checking usage in passing, from the menu bar, a desktop widget, the iPhone companion app, or an iPhone widget, and need trustworthy glanceability more than exploration.

## Product Purpose

Headroom shows remaining AI-subscription usage, reset timing, renewal context, and optional API spend without exposing credentials or making users open provider dashboards. Success means the user can answer "how much room do I have left?" in a few seconds, with every provider presented as a peer across Mac and iPhone surfaces.

## Brand Personality

Quiet, precise, premium. The interface should feel native and calm, with enough craft to feel considered but not enough decoration to distract from usage data.

## Anti-references

Avoid marketing-site gloss, decorative glassmorphism, provider-tinted card surfaces, heavy borders, overly elevated cards, and one-off widget treatments that make Mac, iPhone, and companion surfaces feel unrelated. Claude and Codex cards should use the same material system; provider color belongs in iconography, labels, and usage bars only.

## Design Principles

1. Make comparison feel fair: Claude and Codex are sibling data objects, so their containers should not imply different status unless the data itself differs.
2. Preserve native restraint: use system-like materials, shadows, and spacing that sit comfortably on macOS and iOS surfaces.
3. Optimize for glanceability: percentages, reset labels, and freshness should be legible before the user studies the UI.
4. Share decisions across surfaces: app, iOS widgets, and macOS widgets should reuse tokens and visual techniques whenever the interaction model allows it.
5. Let alerts be explicit: stale, pending, or attention states should use clear state treatments, not accidental material differences.

## Accessibility & Inclusion

Prioritize legibility in light and dark modes, maintain high contrast for labels and percentages, avoid relying on provider color alone for meaning, and respect reduced-motion settings.
