10 menu-bar glyphs & matched macOS app icons

Ten ways to say “room to spare.”

The name changed to Headroom, so the icon should read as remaining capacity — the space you still have — not a generic dial. Each concept below is a matched pair: a menu-bar glyph (a single-color template that macOS tints by severity — green when healthy, amber, then red) and a macOS 26 app icon (a full-color glass squircle that carries the depth and brand story a template can’t).

Use the controls to flip the menu bar between light & dark and to preview how each glyph looks tinted at every severity — the real test of a template icon.

My picks: since the app is provider-neutral and the whole point is space left before you run out, the concepts that literally encode remaining room read best — Clearance, Ring, and Vessel (marked Recommended). The current gauge is fine but says “measurement,” not “headroom.”

Turning a pick into shipped assets

  • Menu bar: export the chosen glyph as a 1×/2× template PDF (single color, isTemplate = true) and swap the Image(systemName:) in MenuBarLabel.swift for it — the severity tinting already in place keeps working.
  • App icon: render the squircle at 16 → 1024 px into an AppIcon.appiconset (or an .iconset → iconutil -c icns), then set CFBundleIconFile in the app bundle.
