Ten Lock Screen widgets, built from the four widget styles

Eight of these are Lock Screen versions of Nested Meter, Vessel Hero, Tightest First and Liquid Level: one circle and one rectangle for each style. The other two are new ideas the Lock Screen makes possible: a refill countdown, and the text line beside the date. Every widget is drawn the way the Lock Screen draws widgets, in one white ink with no colour. The bar at the top switches wallpaper, data, how low limits are flagged, and Always On.

Three sizesCircle 72 × 72 · Rectangle 160 × 72 · Inline 234 × 26 pt (6.1″ iPhones; Pro Max-class phones run 76 / 172 × 76 / 257 × 26). Under the clock you get four circles, two rectangles, or one rectangle and two circles, plus one inline line beside the date.
No colourThe Lock Screen draws widgets in vibrant mode: one white ink at different strengths, tinted by the wallpaper. Green, amber and red can’t come through, so a low limit has to read from the number and the shape. Headroom’s shared widget views already send vibrant down their monochrome branch.
One provider per circleA circle only has room for one provider, so these need a Provider option in Edit Widget (Automatic, Claude, Codex, Grok, Cursor). The data the Mac syncs already includes all four providers, so the widget data format doesn’t change (schema stays 3).
Trust at a glanceThere’s no room for “From Mac · 4 min ago”. Stale values dim to half ink, and a window with no value shows “—”, never 0% (R11). That makes the deferred “dim when the Mac’s data is old” item (BUGS.md) matter more here.
Always OnWhen the phone is locked face-up, the system dims widgets further. Large filled areas should thin out: the liquid fades to a faint tint (isLuminanceReduced). Toggle Always On above to see it.
Platform and paritymacOS has no Lock Screen widgets, so this is iPhone and iPad only, and nothing changes on the Mac. Every idea works for Claude, Codex, Grok and Cursor, using each provider’s main account. Apple Watch complications use the same three sizes, so these designs would also carry over to a Watch app.

How they’d ship

Keep the four style names; add a Provider option

Ideas 01–08 fill a grid: each of the four styles gets one circle and one rectangle. That lets the Lock Screen keep the Style names people already pick in Edit Widget, so each size has one drawing per style.

  • Recommendation: a separate “Headroom” Lock Screen widget with its own Edit Widget: Style and Provider, and no Color because the Lock Screen can’t show colour. It also leaves the home widgets’ just-shipped in-place migration (KTD1) alone. The alternative is adding the Lock Screen sizes to the current widget, which is simpler but shows a Color option that does nothing there. Whether one widget can hide Color for the Lock Screen sizes needs checking in WidgetKit.
  • Provider: Automatic (the default) means the first widget provider for a circle (the same rule as small Vessel Hero, R6), and both widget providers for a rectangle or the inline line. For Tightest First, Automatic searches every provider. Choosing Claude, Codex, Grok or Cursor pins the widget to that one. This brings back the “choose a provider per widget” idea the widget-styles plan deferred, but only for the Lock Screen. Whether the home small Vessel Hero and Liquid Level should get it too is a separate parity call.
  • New pieces: Lock Screen sizes (.accessoryCircular, .accessoryRectangular, .accessoryInline) in the iOS widget extension; Lock Screen ink values (marked PROPOSAL in this file’s CSS); a short window name for circles (Cursor’s pools as “Models” and “Other”, a proposal; rectangles and the inline line use the full “Cursor Models” and “Other Models” where they fit, and never a bare “Cursor 69%” that could read as Cursor’s total); a vessel image for the inline line. Every per-style decision stays in tested Core recipes, as with the home widgets.
  • If you’d rather start small: 03 Tightest Gauge (the most useful single glance), 01 Vessel Badge (the brand), 05 Nested Rows (shows the most with no setup), 10 Inline Readout (space beside the date that would otherwise go unused).
