Notifications, as it will ship.

The rule list from option C, now fully open: any number of reminders, each with its own lead time in hours or days and its own “% left” threshold. It starts with two defaults, and a second tile adds the Codex banked-reset notice. Everything in the window works. Edit a number, change a unit, add or remove a reminder, and watch the preview on the right update.

Changed since the options doc (19 Sep). No four-rule cap, and lead times are typed, not picked from a fixed list. A new Banked resets tile covers Codex only, because only Codex reports banked resets. Banner copy puts “% left” first and drops the invented “about a week of normal use” pace line.

How it behaves

The parts the picture can’t show.

Editing rules

  • Lead time is a number plus hours or days: 1–48 hours or 1–30 days. The percentage is 1–100% left.
  • You can add any number of reminders. A new row copies the shortest one and halves its lead time, so it lands somewhere useful.
  • Rows re-sort, longest lead first, once an edit is committed (Return, or leaving the field). They don’t jump while you type.
  • Removing the last reminder leaves an empty list with “Add reminder”. The switch stays on, and the help line says nothing will fire.
  • Reset to defaults appears only when the rules or scope differ from the defaults.

When a reminder fires

  • For every provider and every account, on each window kind ticked in Applies to.
  • At most once per rule per reset. Relaunching Headroom doesn’t repeat a reminder.
  • Never from stale or unavailable data, and never for a window without a real reset time.
  • If several rules come due in the same refresh (two identical rules, or the Mac waking from sleep), you get one notification.
  • A rule only applies to windows longer than its lead time. A “2 days” rule never touches a 5-hour window.

Permission & limits

  • macOS asks for permission the first time either switch turns on, never at launch.
  • If you deny it, both switches go off and dim, and a notice at the top offers Open System Settings…. The pane re-checks each time Settings opens.
  • These are Mac notifications from the running app. If Headroom is quit or the Mac is asleep, nothing arrives. iPhone push is a separate project.
  • Banked resets are Codex-only because no other provider reports them. That’s a data limit, not a scope choice. The first count Headroom sees for an account never fires, and neither does a drop.
