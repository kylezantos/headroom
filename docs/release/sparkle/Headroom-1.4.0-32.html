Settings, reorganized — and meters you can tune

  • Settings, reorganized. Six sections in a sidebar, with live previews of the popover, menu bar, and widgets that update as you change a setting.
  • Choose how meters look. Pick a format, shape, and fill in Appearance. Color as event keeps meters quiet until usage runs low.
  • Color account names by provider. An optional display setting tints each account title with its provider's brand color.
  • Readable on light wallpapers. The menu bar label follows the menu bar's own appearance, so it stays legible over bright desktops.
  • A calmer popover. Cleaner account rows, sharper meters, subtle motion when values change, and a clearer edge when the list scrolls.
