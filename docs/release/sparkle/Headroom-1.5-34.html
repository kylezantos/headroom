Your menu bar, your widgets, and reminders before usage resets

  • Arrange the menu bar. Add, remove and reorder provider pills in Settings › Menu Bar, and choose which limit each pill follows: 5-hour, weekly, a model limit, either Cursor pool, or Closest to limit.
  • Use it before it resets. Optional notifications tell you when a limit is about to reset with usage still left. Codex can also tell you when a new banked reset arrives. Both are off until you turn them on in Settings › Notifications.
  • Pick a widget style. Each Mac widget can be Nested Meter, Vessel Hero, Tightest First or Liquid Level, Always colored or Only when low. Choose in Edit Widget.
  • More accounts, smarter refreshes. Up to 20 accounts per provider for Claude, Codex and Grok. Each account refreshes on its own schedule, and a manual refresh shows each account’s result as it lands.
  • More detail. Codex shows banked resets on its plan badge. Cursor shows its Cursor Models and Other Models pools separately.
  • Clearer and faster. Loading, waiting and fresh readings each look different. An account that needs attention shows one clear action. The popover opens instantly at full height.
  • About and updates. A new About pane, and an option to download and install updates automatically.
