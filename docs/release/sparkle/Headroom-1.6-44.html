GitHub Copilot joins Headroom

  • Track GitHub Copilot. Turn it on in Settings › Accounts to read usage from the official Copilot CLI. Copilot supports one account; usage outside the CLI can take longer to appear.
  • Send Feedback. Open a pre-filled email to support@zantos.co from About on your Mac or iPhone, with optional diagnostics you can review before sending. Headroom sends nothing itself.
  • More reliable on macOS 15. Changing styles no longer crashes Settings, and the popover header stays visible without clipping.
  • Smoother Claude checks. Chrome’s startup question opens for you to answer, and usage checks stay out of Remote Control.
  • Clearer account details. Plan names read as words, with fewer unnecessary sign-in prompts.
