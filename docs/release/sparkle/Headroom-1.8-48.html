OpenCode Go and Antigravity

  • Track OpenCode Go. See 5-hour, weekly and monthly limits for every OpenCode Console account. Requires the official OpenCode CLI 2.2 or newer; upgrading from 1.x is your choice because it changes OpenCode’s data.
  • Track Antigravity. See the Gemini and Claude & GPT quota pools, their 5-hour and weekly resets, and any remaining AI credits through the official agy CLI 1.5.9 or newer. The “Show 5-hour windows” switch lets you focus on weekly limits.
  • New providers across your devices. Turn on OpenCode or Antigravity in Settings → Accounts. Both work with menu bar indicators, widgets, reminders and iCloud sync to an updated iPhone companion. Widgets show each provider’s main account; Antigravity supports one account.
  • More reliable Claude readings. Usage checks ignore inherited Anthropic API keys and auth tokens so the CLI reads your subscription. A damaged weekly heading no longer hides the all-models weekly limit.
  • Popover shadows stay intact. Scrolling the account list no longer clips card shadows.

This is our first release since Headroom became open source. Thanks to Matt Van Horn (@mvanhorn) for Antigravity support and the Claude API-key fix.

Antigravity’s CLI can open one browser sign-in page when signed out; Headroom then waits for you to retry or sign in. Its configured MCP servers start during checks, and the CLI writes local logs. See the privacy policy for details.
